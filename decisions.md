# Decisions

Решения шаблона (frontend, LLM, деплой на VM, слайды) сняты выбором ТЗ 6 — они остались в git-истории `decisions.md` репо `beif3ng/hackathon`.

| Дата | Решение | Почему |
|---|---|---|
| 2026-11-20 | «Контракт» — по ТЗ и уточнениям v1.1; при расхождении правы уточнения. `scenarios_examples.json` — примеры: сброс состояния, `client_ip` и `advance` обеспечивает стенд жюри | уточнения выданы позже ТЗ и задают коды ответов, по которым идёт автопроверка |
| 2026-11-20 | Счётчик неверных вводов — на номер, не на OTP | на OTP новый `send` между попытками обнулял бы защиту от перебора |
| 2026-11-20 | Продукт — вход по SMS для малого бизнеса: перебор кода и SMS pumping, «сэкономлено N сом». SIM swap отклонён | жюри (19:45) требует идею и применение для 10 баллов демо; при SIM swap потерявший телефон абонент не получит код |
| 2026-11-20 | Продуктовые функции не меняют обязательную часть; меняющее ответы API — за env-флагом, по умолчанию выключенным | обязательные пункты и автопроверка (40 баллов) остаются; скрытые сценарии не должны получить лишний 429 |
| 2026-11-20 | Без трейлеров Claude в коммитах и PR; запушенную историю не переписываем, `CLAUDE.md` остаётся | решение A; force push ломает клон B |
| 2026-11-20 | Задание — ТЗ 6 «OTP-сервис». Из шаблона берём только backend: без frontend, LLM, SQLModel, деплоя на VM и `pitch/`; новый репо одним коммитом | оценка — автопроверка API по README у жюри; остальное баллов не даёт и мешает запуску на чистой машине |
| 2026-11-20 | Хранилище — in-memory под одним `threading.Lock`, uvicorn 1 worker; Redis — только бонус через Docker Compose (`REDIS_URL`) | запуск у жюри без Docker и внешних сервисов; атомарность `verify` |
| 2026-11-20 | Python 3.12+, не совместимость с 3.10 | регламент только рекомендует 3.10+; свежий FastAPI требует 3.11+ |
| 2026-11-20 | Docker — только бонус (compose + Redis), основной запуск — `pip` + `uvicorn` по README | заменяет «Docker только на VM»: VM больше не нужна |
| 2026-11-20 | Сроки: freeze 08:00, последний push 08:45, дедлайн 09:00 | заменяет freeze 09:00 / сдачу 11:30: автопроверка стартует сразу после 09:00 |
| 2026-11-20 | Дашборд (бонус) — один статический HTML, его отдаёт FastAPI | React и Node не нужны; заменяет shadcn / impeccable / orval |
| 2026-11-20 | Идея (демо-сценарий) и задачи — в `CLAUDE.md`, не в отдельных файлах | агенты сверяются с ними в каждой сессии без отдельного чтения; churn `CLAUDE.md` за ночь неважен |
| 2026-11-19 | Не спим | решение команды; риск ночи закрывает правило «03:00–06:00 без рискованных изменений» |
| 2026-11-19 | Браузер для агентов — `agent-browser`, не `chrome-devtools-mcp` | CLI без MCP, страница как компактный текст; тест на Windows прошёл 2026-11-20 |
| 2026-11-19 | B — collaborator, не fork | коммиты в fork не идут в contribution graph; Contributors и pin работают и для collaborator |
| 2026-11-19 | В репо — GitHub-логины (`beif3ng`, `acided`), не имена | репо станет public, историю не переписываем |
