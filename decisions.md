# Decisions

Решения шаблона (frontend, LLM, деплой на VM, слайды) сняты выбором ТЗ 6 — они остались в git-истории `decisions.md` репо `beif3ng/hackathon`.

| Дата | Решение | Почему |
|---|---|---|
| 2026-11-21 | Линтер — ruff, закреплён версией 0.17.6 (`required-version` в `pyproject.toml`), правила — дефолт этой версии. Линтеры для YAML / Dockerfile / HTML не добавляем | решение A: другой версии ruff соответствует другой дефолтный набор правил; `compose config`, hadolint и yamllint чистые (только длина строк), а biome / prettier потребовали бы Node |
| 2026-11-21 | Лого и аватар — «OTP Shield»: щит с 6 крупными точками кода, акцент mauve; файлы в `otp-service/assets/`, не в `hackathon/pitch/` | решение A из 4 вариантов (mauve / green, мелкие / крупные точки); бренд продукта живёт в репо продукта, слайды берут лого по относительному пути |
| 2026-11-21 | Слайд 1 — 826 млн сом (потери жителей КР от киберпреступников за 2025, 24.kg) + $1,15 млрд (SMS pumping в мире за 2023, Mobilesquared / Enea) + 1 040 сом за ночь одного бота | по КР нет цифр именно про pumping и перебор кода; местная цифра — масштаб проблемы, мировая — что под угрозой бюджет бизнеса |
| 2026-11-20 | Палитра — Catppuccin: Mocha для `/dashboard` и бота; Latte для `/demo` и слайдов; лого — две версии без плашки: акцент Mocha на тёмном фоне, акцент Latte на светлом | решение A: готовая палитра вместо своей; тёмный дашборд — привычный вид мониторинга, светлый `/demo` похож на обычный магазин; светлые слайды не выцветают на проекторе в светлом зале; у Mocha и Latte одинаковые по смыслу цвета (green / red / peach) |
| 2026-11-20 | Запуск у жюри — `uvicorn ... --no-proxy-headers`: IP только из соединения, XFF не принимается. Режим подмены часов для жюри не делаем — `advance` они реально ждут | уточнение жюри: стенд ходит с `127.0.0.1` / `127.0.0.2` без XFF; дефолт uvicorn верит XFF с `127.0.0.1`, и атака с подменой XFF обошла бы IP-лимит. Режим часов — лишний код и риск ночью, баллов не даёт |
| 2026-11-20 | Номер без активности 24 ч (`max(SEND_WINDOW, OTP_TTL, LOCK_SECONDS, 86400)`) забывается целиком — и в памяти, и в Redis. Заменяет 900 с | одно поведение в обоих режимах; словарь номеров в памяти не растёт без предела (red team B, L2). 900 с давали 401 вместо 410 на истёкший код при `advance` ≥ 900 (ревью B) |
| 2026-11-20 | Код на демо доставляет Telegram-бот @otp_shield_bot (`app/sms_gateway.py`, только в `compose.prod.yaml`): номер привязывается своим контактом, чужой контакт отклоняется | решение A: жюри получает код на свой телефон; правило «нет HTTP-метода для кода» не нарушено — шлюз отдельный процесс, как SMSC |
| 2026-11-20 | Деплой на VM вернули только для демо: https://otp.beifeng.dev, auto deploy на push в `main`, Caddy + `compose.prod.yaml`. Запуск у жюри не меняется | решение A: демо по домену; uvicorn `--proxy-headers` только в прод-compose, где backend доступен лишь через Caddy, а Caddy перезаписывает `X-Forwarded-For` |
| 2026-11-20 | `SMS_PRICE_SOM` = 1,04 сом — минимальная официальная цена SMS Beeline KG (розничные тарифы beeline.kg, «Стартовый» / «Базовый»); на дашборде «сэкономлено не меньше N сом». Заменяет 1,76 (агрегатор smspro.nikita.kg) | официального B2B-прайса нет, цены агрегаторов — третья сторона; A2P для бизнеса дороже розницы, поэтому официальная розница — честная нижняя граница |
| 2026-11-20 | Оба работаем в `main` без веток; отдельная ветка — только через `claude -w` для рискованного (Redis). `git pull --rebase` в начале задачи и перед push | зоны A и B не пересекаются по файлам; ветки и merge ночью — лишние затраты, а тесты B должны сразу гонять свежее ядро |
| 2026-11-20 | Презентация возвращена: 7 слайдов, генератор остаётся в старом репо `hackathon/pitch/` (pptxgenjs → `pitch.pptx` → Google Slides), в `otp-service` не копируем | жюри (20:33): «презентацию лучше сделать хотя бы маленькую»; пайплайн уже проверен, а в `otp-service` Node не нужен для запуска у жюри |
| 2026-11-20 | «Контракт» — по ТЗ и уточнениям v1.1; при расхождении правы уточнения. `scenarios_examples.json` — примеры: сброс состояния, `client_ip` и `advance` обеспечивает стенд жюри | уточнения выданы позже ТЗ и задают коды ответов, по которым идёт автопроверка |
| 2026-11-20 | Счётчик неверных вводов — на номер, не на OTP | ТЗ: «после 5 неверных вводов — блокировка номера»; «относящихся к активному OTP» в уточнениях — какие вводы считаются, не счёт на OTP. На OTP новый `send` между попытками обнулял бы защиту от перебора |
| 2026-11-20 | Продукт — вход по SMS для малого бизнеса: перебор кода и SMS pumping, «сэкономлено N сом». SIM swap отклонён | жюри (19:45) требует идею и применение для 10 баллов демо; при SIM swap потерявший телефон абонент не получит код |
| 2026-11-20 | Продуктовые функции не меняют обязательную часть; меняющее ответы API — за env-флагом, по умолчанию выключенным | обязательные пункты и автопроверка (40 баллов) остаются; скрытые сценарии не должны получить лишний 429 |
| 2026-11-20 | Без трейлеров Claude в коммитах и PR; запушенную историю не переписываем, `CLAUDE.md` остаётся | решение A; force push ломает клон B |
| 2026-11-20 | Задание — ТЗ 6 «OTP-сервис». Из шаблона берём только backend: без frontend, LLM, SQLModel, деплоя на VM и `pitch/`; новый репо одним коммитом | оценка — автопроверка API по README у жюри; остальное баллов не даёт и мешает запуску на чистой машине |
| 2026-11-20 | Хранилище — in-memory под одним `threading.Lock`, uvicorn 1 worker; Redis — только бонус через Docker Compose (`REDIS_URL`) | запуск у жюри без Docker и внешних сервисов; атомарность `verify` |
| 2026-11-20 | Python 3.12+, не совместимость с 3.10 | регламент только рекомендует 3.10+; свежий FastAPI требует 3.11+ |
| 2026-11-20 | Docker — только бонус (compose + Redis), основной запуск — `pip` + `uvicorn` по README | заменяет «Docker только на VM»: VM больше не нужна |
| 2026-11-20 | Сроки: freeze 08:00, последний push 08:45, дедлайн 09:00 | заменяет freeze 09:00 / сдачу 11:30: автопроверка стартует сразу после 09:00 |
| 2026-11-20 | Дашборд (бонус) — один статический HTML, его отдаёт FastAPI | React и Node не нужны; заменяет shadcn / impeccable / orval |
| 2026-11-20 | Идея (демо-сценарий) и задачи — в `CLAUDE.md`, не в отдельных файлах | агенты сверяются с ними в каждой сессии без отдельного чтения; churn `CLAUDE.md` за ночь неважен |
| 2026-11-19 | Не спим | решение команды; риск ночи закрывает правило «03:00–06:00 без рискованных изменений» |
| 2026-11-19 | Браузер для агентов — `agent-browser`, не `chrome-devtools-mcp` | CLI без MCP, страница как компактный текст; тест на Windows прошёл 2026-11-20 |
| 2026-11-19 | B — collaborator, не fork | коммиты в fork не идут в contribution graph; Contributors и pin работают и для collaborator |
| 2026-11-19 | В репо — GitHub-логины (`beif3ng`, `acided`), не имена | репо станет public, историю не переписываем |
